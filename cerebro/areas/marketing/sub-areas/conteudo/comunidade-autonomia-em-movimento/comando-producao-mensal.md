# Comando padrão — Produção mensal da Comunidade Autonomia em Movimento

Use este comando quando for necessário produzir o calendário completo de conteúdos da Comunidade Autonomia em Movimento para um mês.

## Comando

```markdown
Crie o calendário completo de conteúdos da Comunidade Autonomia em Movimento para o mês de [MÊS/ANO].

Informações do período:

Etapa atual do programa: [INÍCIO / CONSTRUÇÃO / CONSISTÊNCIA / AUTONOMIA];

Quantidade aproximada de participantes: [NÚMERO];

Pilares trabalhados recentemente: [INFORMAR];

Principais dificuldades observadas: [INFORMAR];

Datas ou acontecimentos relevantes: [INFORMAR];

Conteúdos dos últimos 90 dias: [ANEXAR OU INDICAR O LOCAL];

Orientações específicas da Dra. Lígia: [INFORMAR].

Produza todos os conteúdos de segunda a sexta, prontos para envio no WhatsApp.

Trabalhe um pilar principal por semana. Caso o mês tenha mais semanas do que pilares selecionados, utilize a última semana para integração dos pilares, retomada e planejamento pessoal.

Entregue:

Visão geral do mês;

Objetivo de cada semana;

Tabela com datas, temas, formatos e classificação;

Mensagem completa de cada dia;

Enquetes com todas as alternativas;

Roteiros completos de áudio ou vídeo;

Textos para os cards;

Orientações para a equipe;

Lista dos conteúdos que exigem validação da Dra. Lígia;

Espaço semanal reservado para eventual notícia recente.

Não envie ou publique nenhum conteúdo. Apenas prepare o material para revisão humana.
```

## Uso operacional

Antes de produzir o mês, o agente deve:

1. Consultar o `guia-editorial-operacional.md`.
2. Consultar conteúdos dos últimos 90 dias, se existirem.
3. Identificar dias úteis do mês solicitado.
4. Distribuir os seis pilares com equilíbrio.
5. Variar formatos para não repetir o mesmo formato por mais de dois dias consecutivos.
6. Separar conteúdos Verdes e Amarelos.
7. Não gerar conteúdo Vermelho para publicação.
8. Quando houver espaço de notícia recente, pesquisar fonte original dos últimos 7 dias antes de incluir.
9. Entregar tudo para revisão humana, sem publicar automaticamente.
