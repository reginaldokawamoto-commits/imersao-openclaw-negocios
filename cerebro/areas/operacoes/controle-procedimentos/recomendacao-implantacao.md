# Recomendação de implantação — Follow-up de procedimentos

## Princípio

Não alterar diretamente a planilha operacional atual sem antes testar. Ela já contém informações importantes e não deve ser colocada em risco.

## Recomendação principal

Criar uma **planilha complementar de follow-up**, ou uma aba separada em cópia da planilha atual, com poucos campos obrigatórios. A planilha atual continua sendo a base histórica/operacional, e a nova visão serve apenas para cobrança e acompanhamento semanal.

## Por que não criar uma planilha grande do zero

O problema principal hoje não parece ser falta de campos, mas falta de preenchimento consistente. Se criarmos uma planilha nova muito completa, há risco de virar mais uma base desatualizada.

## Modelo sugerido: controle mínimo obrigatório

A nova visão deve ter poucos campos, focados em ação:

1. Paciente
2. Procedimento
3. Tipo de caso: `particular`, `convênio`, `misto`, `negativa/reclamação`
4. Status atual
5. Paciente aceitou orçamento? `sim`, `não`, `aguardando`, `não se aplica`
6. Foi para reclamação? `sim`, `não`, `não se aplica`
7. Último contato
8. Próximo follow-up
9. Próxima ação
10. Responsável

## Estratégia segura de implantação

### Fase 1 — Sem mexer na planilha original

- Criar uma cópia da planilha atual ou uma planilha complementar.
- Testar por 2 semanas com os casos novos ou casos ativos.
- Validar se Paola consegue preencher sem aumentar muito o trabalho.

### Fase 2 — Simplificar o uso

- Usar listas suspensas para status e tipo de caso.
- Usar cores automáticas para follow-ups vencidos.
- Criar filtros salvos: `vencidos`, `convênio aguardando`, `reclamação pendente`, `particular sem resposta`.

### Fase 3 — Só depois integrar

Se funcionar bem, decidir se:

- mantém como planilha complementar;
- vira uma aba oficial da planilha atual;
- ou substitui parte do controle antigo.

## Recomendação final

Começar com uma **planilha complementar enxuta**, não uma nova base complexa e não uma edição direta na planilha atual.

A prioridade é reduzir atrito de preenchimento. O controle precisa responder só três perguntas:

1. Quem está parado?
2. Qual é a próxima ação?
3. Quem precisa ser cobrado hoje?
