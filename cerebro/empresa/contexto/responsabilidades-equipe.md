## Como registrar novas responsabilidades

Para cada atividade, registrar sempre que possível:

| Campo | Como preencher |
|---|---|
| Atividade | Nome objetivo da tarefa |
| Responsável principal | Quem executa ou garante que aconteça |
| Apoio | Quem ajuda, envia informação ou depende da tarefa |
| Frequência | Diário, semanal, mensal, sob demanda etc. |
| Ferramenta/canal | iClinic, WhatsApp, Telegram, Instagram, planilha etc. |
| Critério de conclusão | Como saber que a tarefa foi finalizada |
| Observações | Regras, exceções, detalhes importantes |
| Status | Ativa, em transição, pausada ou encerrada |
